# Code of Conduct

We want this project to be a friendly place for everyone, whatever their experience, language or background.

**Expected:** be respectful and constructive; assume good intent; criticise code and ideas, not people; keep discussion on topic; help newcomers (issues and docs are welcome in English and Russian).

**Not acceptable:** harassment, insults, discrimination, personal attacks, publishing other people's private information, and spam.

Maintainers may edit or remove comments, issues and contributions that break these rules, and may block repeat offenders.

To report a problem, use the private **Report a vulnerability / contact** options of the repository or contact the maintainer through the profile at <https://github.com/sink3x>. Reports are handled privately.

This text is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
